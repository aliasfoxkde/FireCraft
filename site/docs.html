Quickstart

Open, edit, save, export

The native format is a layered Fireworks PNG. Save as a copy until you trust the round-trip for your own artwork.

  • Create a document or open an existing .fw.png
  • Work with vector and bitmap objects in the same layer stack
  • Save to the native document format, then export a web asset
  • Keep the original artwork until your workflow is proven
command line
# inspect a document
firecraft-cli info artwork.fw.png

# canonical re-emit of a Fireworks PNG
firecraft-cli convert input.fw.png output.fw.png

# export for the web
firecraft-cli export artwork.fw.png artwork.webp

# import a photo into a new document
firecraft-cli import photograph.jpg new-document.fw.png

# start the MCP server for a document
firecraft-cli mcp artwork.fw.png
