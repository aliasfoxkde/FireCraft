Compatibility reference

What round-trips,
and what does not.

A document editor is only as trustworthy as its save path. These tables state the direction of each format support, what the native document preserves, and which platforms have actually published builds.

Interchange

Format direction

Read means the format can be opened into a FireCraft document. Write means the document can be exported to it. A format can be one, the other, or both.

Raster, vector, and layered formats
FormatReadWriteWhat to expect
Fireworks PNGYesYesThe native layered document. Unknown document nodes and chunks are preserved on save; the round-trip is checked against pinned real files.
PNGYesYesImport raster artwork; export flattened output with transparency.
JPEGYesYesImport photographs; export with quality control. No transparency.
GIFYesYesAnimated frames are imported as frames and exported as animation.
WebPYesYesLossy and lossless raster interchange.
SVGYesYesVector interchange through the document model; not every SVG feature has an editable equivalent.
PSDYesYesLayered interchange for artwork hand-off; effect and text semantics are approximated.
TIFFYesYesRaster interchange for print-adjacent hand-off.
BMP / WBMPYesYesLegacy and mobile-oriented raster output.

Direction describes the implemented workflow, not a promise of perfect semantic conversion. Open a copy of important files and inspect the result.

The document

Fidelity is a
non-destructive promise.

A Fireworks PNG is a PNG container with a structured node tree: layers, objects, text, effects, and editor metadata. FireCraft maps that tree into its document model and writes it back.

  • Unrecognized nodes are carried through, not discarded
  • Chunk data is preserved on rewrite
  • Hostile or malformed input returns an error instead of aborting
  • Corpus fixtures are pinned by digest; the round-trip floor only rises

Why this matters

Editable files are archives of decisions. If a save silently drops a node the editor does not understand, the document is damaged even though it still opens — and the damage is invisible until months later.

The preservation rule is enforced in the parser and covered by round-trip tests, not just documented.
