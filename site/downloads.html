Install

Pick the artifact
that matches your system.

Linux x86_64 is the published desktop target today. Debian package for system installs, archive for everything else, web bundle for the browser.

Debian package

For Debian-based distributions. Installs the editor and desktop entry.

shell
sudo apt install ./firecraft_*.deb

Archive

Extract and run without touching the system package database.

shell
tar -xzf firecraft-*.tar.gz
./firecraft/firecraft

Verify the checksum

Compare the artifact against the checksum published with the release.

shell
sha256sum -c firecraft-*.sha256
◆

From source

Build the whole
workspace yourself.

A Rust toolchain compatible with the workspace's declared minimum is the main requirement; platform packages are documented in the toolchain guide. The gate must be green before you trust a local build.

  • Native editor and CLI from the same workspace
  • WebAssembly distribution via the build tool
  • Full verification gate in one command

Platform toolchains ↗

build from source
git clone https://github.com/aliasfoxkde/FireCraft.git
cd FireCraft

# full verification gate
cargo run -p xtask -- ci

# native editor and command line
cargo build --release -p app
cargo build --release -p app-cli

# browser distribution
cargo run -p xtask -- dist --web

Building from source gives you the current development tree, which may be ahead of the last published release and may contain unfinished work.
