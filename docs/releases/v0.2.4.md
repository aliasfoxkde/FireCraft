# v0.2.4 (2026-11-02)

Phase 19 daily-driver batch continued: selection/mask reachability,
real icons, and a canvas context menu.

## Shell reachability (Phase 19.6, selection/mask batch)

- Superselect / Subselect (`selection.selectParents`/`selectChildren`)
- Select Similar (`bitmap.selectSimilar`)
- Feather dialog (Select ▸ Feather…, radius 1–64)
- Expand / contract / border / smooth marquee wired in the menus
- Convert Marquee ⇄ Path (`mask.pathToMarquee`/`marqueeToPath`)
- Save / restore / delete bitmap selections
- Selective-JPEG mask save / restore / remove
- Mask add (reveal/hide all & selection), enable/disable, link/unlink,
  delete (`mask.*` family)

## Canvas competence

- Right-click context menu: picks the object under the pointer when
  the press missed the selection, then clipboard/transform/arrange/
  group verbs through the same action door as the menu bar
- Cross-layer hit-testing: the pointer picks through every visible
  layer of the frame (topmost wins; hidden layers and locked cells
  refuse)
- New layers default to display on (CS6 `DISb`) — they previously
  rendered nothing

## Icons

- Tool strip replaced with the vendored Lucide set (ISC): embedded
  SVGs rasterized at on-screen size, crisp at any DPI, identical on
  desktop and wasm. The Auto Shape flyout keeps its original
  per-shape sketches.

Carried from 19.1–19.5 (first release to include them): transform
handles, path-node editing, gradient editor, command palette,
grid/guides/snap, crisp zoomed canvas, ellipse-shape and color-picker
fixes.

## Verification

- Local gate: all green (`cargo run -p xtask -- ci`)
- Desktop screenshot pass on the icon swap (Xvfb + scrot)
