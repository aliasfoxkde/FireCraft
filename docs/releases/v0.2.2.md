# FireCraft v0.2.2 — release notes (2026-10-19)

## What changed

CLI export error message now correctly lists all 9 supported formats
(png, jpg, bmp, tiff, wbmp, webp, svg, psd, gif). WebOS packaging
dry-run: `appinfo.json` and `host.html` are now staged in `dist/web`
during build. Decision docs added: AVIF decode policy (pure-Rust wasm-safe
decoder), HEIC refusal (patent pools, OS-decoder-only), and smoke
budget (60s virtual time covers app logic, not wasm fetch/compile).

54 unit tests added for the scripting marshal helpers and text lib
helpers.
