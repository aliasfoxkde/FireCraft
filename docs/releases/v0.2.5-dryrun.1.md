# v0.2.5-dryrun.1 — DISPOSABLE REHEARSAL, NOT A RELEASE

> **This tag is a disposable dry run.** It exists to prove that the
> draft-release path works end to end before anyone cuts a production
> tag (issue #99, campaign row T27-19). It is **not** a release of
> FireCraft, it is not published, and it must not be downloaded by
> anyone as a product. The version string carries `-dryrun.1` for
> exactly that reason.

## What this rehearsal covers

The release workflow has never produced a release: the artifact upload
step carried a broken argument form, so the "draft release" the
artifact matrix claimed was never reachable. This run exercises the
whole path — tag push → native build → web build → checksums → asset
upload → draft release creation — against the tree at `main`
(`18c5a52`) with only the version stamps changed.

## What is in this draft

- `firecraft-0.2.5-dryrun.1-linux-x86_64.tar.gz` — desktop shell + CLI
- `firecraft-cli-0.2.5-dryrun.1-linux-x86_64.tar.gz` — CLI alone
- `firecraft_0.2.5-dryrun.1_amd64.deb` — Debian package
- `firecraft-web-0.2.5-dryrun.1.zip` — the WebOS bundle
- `MANIFEST.sha256` — over the three native archives
- `RELEASE_SHA256.txt` — over the five shipped assets

## After the rehearsal

The draft release and the tag are deleted once the assets have been
verified. The receipt — run id, job ids, asset list, digests, and every
defect the run exposed — is recorded in `docs/release/` and on issue
#99. Nothing about this rehearsal changes the production release path;
it only proves the path exists.
