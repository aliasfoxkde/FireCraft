# FireCraft v0.2.0 (2026-10-15)

## Highlights

v0.2.0 shipped the post-parity surface: all M0–M15 milestones closed,
the DOM verb parity campaign complete (268 C / 3 P / 0 M, registry 241),
and the first release targeting the WASM web bundle as a primary
artifact.

- **Shell surfaces** (M13): CS6 tool panel, align/distribute, point
  editing, Auto Shape library
- **Live filters** (M14): 24 kernel families, CS6 filter enumeration
  parity
- **Style/vector depth** (M15): gradient styles, compound paths, masks
- **CS6 DOM parity**: 268 carried / 3 partial (evidence-gated) / 0 missing
- **241-command engine registry**, pinned to the fuzz call table
- **Native WebP** encode (lossless VP8L through `image-webp`) and WebP
  import
- **PNG/JPEG** round trip; **SVG export** with golden parity
- **Web bundle** live at <https://firecraft-web.pages.dev>
