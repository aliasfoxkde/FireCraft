# FireCraft v0.2.1 — hotfix release (2026-10-15)

## What was fixed

v0.2.0's web bundle shipped with a dead browser bridge: File > Open,
Import, and Save did nothing in the browser. The wasm shell panicked on
every bridge call (missing `as_any_mut` override), the smoke check was
reading its own script source (vacuous), and bridge mutations never
repainted the canvas. All three are fixed.

**Fixed:**
- **web**: eframe shell now overrides the wasm-only `as_any_mut` entry,
  so bridge calls (postMessage open/apply/export, the hidden file input,
  downloads) reach the app instead of panicking.
- **web**: bridge-driven mutations now repaint the canvas — an opened
  document renders immediately, with zero input events.
- **build**: the `dist --web` bridge smoke strips `<script>` bodies
  before asserting on the DOM and also requires the failure marker's
  absence; it can no longer pass on its own inputs.
- **build**: the fmt gate now covers the workspace-excluded `web`
  crate explicitly.

The deployed instance at <https://firecraft-web.pages.dev> serves this
release and was verified in a real browser: open → draw → save, end
to end.
