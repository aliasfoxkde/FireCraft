## 4. Audit report (2026-11-03 session)

Findings from the pre-release audit, with dispositions:

1. **WebOS appinfo stamping was a silent no-op (fixed this release).**
   `packaging/webos/appinfo.json` hardcoded a literal version, so the
   dist `replace` never fired — the v0.2.3→v0.2.4 window shipped
   pinned to 0.2.3. Fixed: `@VERSION@` placeholder + a dist gate that
   fails on a template without the placeholder or on any post-stamp
   residue (`host.html` exempt, version-free by design).
   *Class:* release-automation; the fix is a gate, not a procedure.
2. **Aegis baseline rot (fixed this release).** The baseline carried
   ~1046 entries for `source/` and `temp/` files that are now
   ignore-rule excluded, and `log/devlog.md` was git-ignored but not
   aegis-ignored — this session's devlog entries (CS6 command ids) tripped
   the zip-code rule and failed the gate. Fixed: baseline regenerated
   (entries 1046 → 517), `log/` added to `.aegisignore`.
   *Class:* tooling hygiene; root cause was ignores accreting without
   a baseline re-derive step.
3. **Docs quoting stale derived numbers (fixed this release).** The
   census figure appeared as 171/144/131 in different docs while the
   live bar read 129. Fixed: `reachability_census` now prints the live
   number and docs quote derived output; the ceiling gate
   (`inert_count_never_rises`) prevents silent rises.
   *Class:* documentation drift on hand-maintained numbers — the
   standing rule is quote-a-derived-value, never hand-count.
4. **Window menu 24/24 inert (open).** Largest remaining reachability
   block; owner: Phase 19.6 batch 3 (panel toggles). Next action
   tracked in `docs/NEXT.md`.
5. **49 CS6 scripts lack a host-name mapping (open).** The headless
   runner skips them; each mapping is a small registry addition.
   Owner: scripting phase backlog.
6. **SVG export drops 8 live-effect families by design (accepted).**
   Each maps to no SVG primitive; notes are emitted in the round-trip
   report. Disposition: documented behavior, revisit only if a viewer
   rasterization path is added.

Residual risk: the perf budget suite ran on the dev profile of this
host (Ryzen 7 5700U); numbers are host-relative, enforced as budgets,
not absolutes.
