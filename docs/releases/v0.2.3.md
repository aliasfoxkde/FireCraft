# FireCraft v0.2.3 (2026-10-24)

Phase 11.4 pixel-selection tools + paint/IO batch.

## Pixel selection (Phase 11.4)

- Marquee, ellipse, lasso, polygonal-lasso, and magic-wand tools with
  marching-ants overlay
- Select all / deselect / inverse / feather
- Expand, contract, border, smooth (`bitmap.adjustPixelSel`)
- Selection-mask move (`bitmap.moveSelectionMaskBy`); fuzz driver
  covers the new verbs

## Paint / IO

- Brush and eraser hardening
- fwpng tile-decode fixes
- Lossy WebP export via libwebp-sys (feature-gated `lossy-webp`,
  native only — wasm unaffected)
- CLI lossy-WebP plumbing (`--quality`)

## Verification

- Local gate: all green (aegis, coverage, fmt, clippy, test, layers,
  wasm, corpus, floor, scripts, golden, svg-golden, svg-roundtrip,
  web-golden, perf, fuzz, parity, scorecard, changelog)
- GitForge CI: 7/7 jobs green on `00d2bf8` after the CI image
  re-ship (`firecraft-ci-rust:1` rebuilt against the moved
  lockfiles; the two prior runs died on image-pull 404)
