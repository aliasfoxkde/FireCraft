# FireCraft v0.2.5 (2026-11-03)

Phase 19 daily-driver batch continued: path-node add/delete, the
canvas geometry dialogs, and object duplication.

## Path competence (Phase 19b.1)

- Double-click on a path segment inserts an anchor at the click point
  (splitting the segment via `vector::insert_point`)
- Double-click on an existing anchor deletes it
  (`vector::delete_point`), with the two-endpoint guard preserved
- Both fold into a single "Reshape" undo step; covered by new
  `crates/vector/src/tests.rs` round-trip batteries

## Shell reachability (Phase 19.6, batch 2)

- Modify ▸ Canvas ▸ Canvas Size… — absolute canvas resize with the
  CS6 nine-anchor grid
- Modify ▸ Canvas ▸ Canvas Color… — document matte color
- Edit ▸ Duplicate (Ctrl+Alt+D) and Edit ▸ Clone (Ctrl+Shift+C),
  both bound to `object.duplicate` — the copy lands on top, a
  following drag separates it (CS6 behavior)

The inert census drops **144 → 129 of 289** menu items; the
`inert_count_never_rises` ceiling gate is re-pinned at 129, and the
figure is now printed by `reachability_census` (`--nocapture`) so the
docs quote a derived number.

## Community / policy

- `.github/` added: Code of Conduct, Contributing guide, Security
  policy, PR template, issue templates (bug / feature)

## Release-path defect fix (WebOS appinfo stamping)

- **Defect:** the v0.2.3→v0.2.4 window shipped a WebOS
  `appinfo.json` pinned to **0.2.3** — the template hardcoded a
  literal version, so the dist stamping `replace` was silently a
  no-op.
- **Fix:** `packaging/webos/appinfo.json` now carries an
  `@VERSION@` placeholder, and `xtask dist --web` gates on it: a
  template with no placeholder fails the build, and any file still
  carrying `@VERSION@` after stamping fails too (`host.html` is
  version-free by design and exempt). Verified: the staged bundle's
  appinfo reads 0.2.5.
