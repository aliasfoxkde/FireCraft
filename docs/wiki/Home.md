# FireCraft Wiki

FireCraft is an independent, clean-room Rust editor for Fireworks-style `.fw.png` documents. It combines vector and bitmap editing with CLI, scripting, MCP and browser-host integration. The repository docs contain the detailed, versioned specifications and current evidence.

## How to read the roadmap

The [Parity Roadmap](Parity-Roadmap) separates unfinished Fireworks CS6 behavior and presentation from newer FireCraft additions. The [CS6-PARITY.md matrix](https://github.com/aliasfoxkde/FireCraft/blob/main/docs/CS6-PARITY.md) is the detailed user-visible inventory; the generated DOM report measures scripting/API verbs and is not a substitute for GUI parity. See [TASKS.md](https://github.com/aliasfoxkde/FireCraft/blob/main/docs/TASKS.md) and [PROGRESS.md](https://github.com/aliasfoxkde/FireCraft/blob/main/docs/PROGRESS.md) for current status.

> **Clean-room boundary:** FireCraft is independent of Adobe. Its behavior references documentation and observation; Adobe source code and artwork are not included.
