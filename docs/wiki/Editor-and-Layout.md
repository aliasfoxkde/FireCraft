# Editor and Layout

FireCraft uses one editing model across the browser and desktop shells. The exact set of visible controls is still being brought closer to Fireworks CS6.

## Canvas and tools

The canvas supports document navigation, object selection, vector editing, bitmap tools, and command-driven edits. See [Usage](https://github.com/aliasfoxkde/FireCraft/blob/main/docs/USAGE.md) for current shortcuts and [Features](https://github.com/aliasfoxkde/FireCraft/blob/main/docs/FEATURES.md) for implemented surfaces.

## Panels

The current shell has a left tool area and independently positioned panel windows on the right. Panel inventory, inspector completeness, and behavior at ordinary viewport sizes remain active work. Some lower panels were only visible in a very tall capture; that is a layout issue, not proof that the normal editor layout is complete.

See the [Parity Roadmap](Parity-Roadmap) and [Phase 22](https://github.com/aliasfoxkde/FireCraft/blob/main/docs/NEXT.md#phase-22--cs6-shell-fidelity-p0-the-looks-and-acts-like-fireworks-phase) for the ordered shell work and visual acceptance criteria.
