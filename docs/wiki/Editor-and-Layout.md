# Editor and Layout

FireCraft uses one editing model across the browser and desktop shells. The exact set of visible controls is still being brought closer to Fireworks CS6.

## Canvas and tools

The canvas supports document navigation, object selection, vector editing, bitmap tools, and command-driven edits. See [Usage](https://github.com/aliasfoxkde/FireCraft/blob/main/docs/USAGE.md) for current shortcuts and [Features](https://github.com/aliasfoxkde/FireCraft/blob/main/docs/FEATURES.md) for implemented surfaces.
