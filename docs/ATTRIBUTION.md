## Original assets (made for this repo)

The five re-created Common Library files under `assets/library/` are
original FireCraft artwork: generated by `cargo run -p xtask -- library-gen`
from the engine registry (vector shapes, text, and a Widget script written
for this project). They re-create the *categories* of CS6's Common Library
content (animations, bullets, buttons, halos, themes) without copying any
Adobe bytes, paths, colors, or names. License: this repository's
(MIT OR Apache-2.0); no third-party material is embedded.

## Reference material (used for study, never committed, never shipped)

- Adobe Fireworks CS6 installation and PortableApps launcher (`source/`,
  git-ignored) — behavior reference and corpus-generation host; © Adobe Inc.
- Extracts of Adobe's published documentation ("Extending Fireworks",
  CS6 help) cached uncommitted under `/var/tmp/` — regeneration recipes in
  `docs/PLANNING.md` §5.4.
- `.jsf` scripts and HTML templates inside the local CS6 install — used as
  behavioral specifications to be re-implemented, not copied.
