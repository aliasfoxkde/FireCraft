# FireCraft keyboard shortcuts

Generated by `cargo run -p xtask -- shortcuts --bless`; do not edit by
hand. The document is written from the same keymap tables the shell
dispatches from, so it cannot drift from the code — the gate fails on
any difference.

FireCraft ships one keymap set by default — CS6's own, taken from the
CS6 `Fireworks.xml` keymap resource — and four alternatives that
rebind the shared verbs. Edit ▸ Preferences ▸ Keyboard chooses the
set; the in-force bindings are also listed in the app's own
**Keyboard Shortcuts** panel (F1).

## Illustrator

Source: Adobe's *Default keyboard shortcuts in Adobe Illustrator* (helpx.adobe.com/illustrator/using/default-keyboard-shortcuts.html).

The verbs this set rebinds. Every other verb keeps the CS6 binding, so
the set is never a regression against the default. The last column is
the vendor's own name for the command, so the row can be found in the
source named above.

| Edit | Deselect | Ctrl+Shift+A | Ctrl+D | Deselect all artwork |
| Modify ▸ Arrange | Arrange to front | Ctrl+Shift+] | Ctrl+F | Bring the selection to the front |
